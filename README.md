# 英文・和文タイピング

日本人のための英語学習タイピングゲームです。**6つの種類**（物語・単語・単語例文・英英辞典・タッチタイピング・ローマ字入力）から選び、英語と日本語をタイピングしながら語彙・読解・入力を鍛えられます。和文はローマ字で入力でき、漢字はそのまま表示されます。

🎮 **デモ**: https://curseoff.github.io/typing-language-learning/

<img src="https://raw.githubusercontent.com/curseoff/typing-language-learning/issue-assets/assets/usage-start.png" alt="スタート画面：種類・レベル・テーマ・範囲・モード・学習モード・終了条件を選ぶ" width="640">

React + Vite 製。ブラウザで動きます（PWA としてインストール・オフライン利用も可）。

## 種類とモード

スタート画面の**タブで種類を選び**、種類ごとのレベル・モードを選んで開始します。タブの並び順は次のとおりです。

### 📖 物語（分岐ストーリー）
テキストを打って進め、**選択肢を打つと分岐**するサウンドノベル風。**海外旅行アドベンチャー**（`travel`）と**クライミング**（`climbing`）の2つを収録し、それぞれ**4つのエンド**があります。発見したエンドと記録（速度ランキング）が残ります。選んだモード（`英語・日本語`／`英語`／`日本語`／`英語訳`／`日本語訳`）がそのまま適用されます。物語は最後まで進めて終わるので、終了条件セレクタはありません。

### 🔤 単語（語彙を覚える）
語彙学習。レベル4段階（`L1 基礎`／`L2 初級`／`L3 中級`／`L4 上級`）× テーマ（`すべて`／`日常`／`旅行`／`ビジネス`）。
- 入力モード：`英語・日本語`／`英語`（和訳→英単語）／`日本語`（英単語→和訳）
- 4択モード：`英語訳`（和訳→英単語を選ぶ）／`日本語訳`（英単語→和訳を選ぶ）。**選択肢を打って選ぶ**

### ✍️ 単語例文（単語を文で使う）
収録した単語を使った**例文**を打つ。レベル4段階（`L1 基礎`／`L2 初級`／`L3 中級`／`L4 上級`）× テーマ（`すべて`／`日常`／`旅行`／`ビジネス`）。
- モード：`英語・日本語`（交互）／`英語`／`日本語`／`英語訳`／`日本語訳`

### 📚 英英辞典（英語で意味を学ぶ）
英語の定義で語彙を学ぶ。単語のサブセットで、収録のあるレベルのみ選べます。
- 入力モード：`英語・日本語`／`英語`（定義文を打つ）／`日本語`（和訳を打つ）
- 4択モード：`単語4択`（英語の定義 → 英単語を選ぶ・回答後に和訳）／`説明4択`（英単語＋意味 → 合う説明文を打って選ぶ）

### ⌨️ タッチタイピング（ブラインドタッチ）
画面を見ずに打つ練習。**40打のドリル**で終了。
- レベル：ホームポジション／上段／下段／数字／すべて
- モード：`やさしい`（打つキーをキーボード上でハイライト）／`むずかしい`（ハイライトなし）
- **指の色分け**と「使う指」表示で運指を誘導

### あ ローマ字入力（かなを打つ）
かな（ローマ字）入力の基礎練習。行グループ別（あ行〜わ行・ん、濁音・半濁音・拗音、ぜんぶ）にかなを打ちます。

### 学習モード（通常／穴埋め）
**単語・単語例文・英英辞典**の**通常入力**（`英語・日本語`／`英語`／`日本語`）を選んでいるときだけ、`通常` と `穴埋め` を切り替えられます（翻訳・4択では出ません）。
- **穴埋め**：`5問ごと`に覚えた語を伏字（`____`）で出題。ヒントは反対側の言語で示され、ミスすると正解が現れます。単語は入力対象をまるごと（`英語・日本語`は英/日どちらか片側）、単語例文・英英は文中の1〜3語を伏字にします。

### 終了条件（単語・単語例文・英英で選択）
プレイの終わり方を選べます（既定は時間60秒）。
- **時間**：30／60／120／180秒　- **文字数**：300／600／1200文字　- **問題数**：10／25／50問
- **サドンデス**：ライフ 1／3／5（ミスした問題数がライフに達したら終了）　- **エンドレス**：`Esc` で終了（30秒以上プレイで記録）

物語・タッチタイピング・ローマ字入力には終了条件セレクタはありません。

### 範囲（復習）
単語・単語例文・英英では、100語単位の**固定範囲**を選ぶと、毎回同じ順で繰り返し復習できます（範囲指定なし＝全体から出題）。

## 共通の特徴

- **自由なローマ字入力**：`shi`/`si`、`tsu`/`tu`、`ji`/`zi`、促音 `gakkou`、撥音 `n`/`nn` などどれでもOK。入力した綴りに表示が追従
- **日本語は漢字で表示**：ローマ字で打つと、対応する漢字が順に色づく
- **4択は打って選ぶ**：選択肢の文字も打った分だけ色づき、進捗がわかる
- **間違えると正しく打つまで進めない**（打ち間違いは消さなくてよい）
- **文末記号も入力**：英 `.` → 和 `。`／英 `?` → 和 `？`
- 速度（打/分）・時間・ミス・正確率を記録。**記録ランキングは種類・レベル・モード・終了条件ごと**（範囲を選べばその範囲別にも）ブラウザ内へ永続化
- **収録一覧**：スタート画面で「記録ランキング / 収録一覧」を切り替え、収録された問題と**問題ごとの記録（練習回数・平均ミス・打/秒）**を確認できる

## 使い方

詳しい遊び方・操作・各モードの説明は **[docs/USAGE.md（使い方ガイド）](docs/USAGE.md)** にまとめています。

ざっくりした流れ：

1. ブラウザで[デモ](https://curseoff.github.io/typing-language-learning/)を開く
2. スタート画面で **種類 → レベル → モード** を選ぶ（`↑` `↓`＝項目、`←` `→`＝選択、`Enter`＝スタート、`Esc`＝戻る）
3. 英文はそのまま、和文はローマ字で入力（漢字表示のまま色づく）。4択は選択肢を打って選ぶ
4. 打ち間違えると正しく打つまで進めません。終了すると結果・記録ランキングが表示されます
